# Ferret Frontend

Next.js frontend for Ferret — an interactive architecture graph and AI Q&A tool for codebases.

## Setup

```bash
npm install
npm run dev
```

Requires the backend to be running on `http://localhost:8000`.

## Key Dependencies

- **React Flow** (`reactflow`) — interactive graph rendering
- **dagre** — auto-layout for sub-graph overlays
- **lucide-react** — UI icons
- **Tailwind v4** — styling (CSS-based config, no `tailwind.config.ts`)
